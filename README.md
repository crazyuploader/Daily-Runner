# Link Checker

Check and validate links using Lychee.

## Status

[![Links Status](https://github.com/crazyuploader/Daily-Runner/actions/workflows/link-checker.yml/badge.svg?branch=my-learning-journey-links-checker)](https://github.com/crazyuploader/Daily-Runner/actions/workflows/link-checker.yml)

## Features

- Automated link checking
- Lychee integration

## Technologies Used

- **[Lychee](https://github.com/lycheeverse/lychee)**: ⚡ Fast, async, stream-based link checker written in Rust. Finds broken URLs and mail addresses inside Markdown, HTML, reStructuredText, websites and more!
